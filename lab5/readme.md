# Express


Fast, unopinioneted, minimalist web framework for node.js


1. create npm project `npm init -y`
2. update package.json
    `type:module`
3. install nodemon with `npm i nodemon -D`
4. install express woth `npm i express`
5. update package.json 
```
    "start": "node app.js",
    "dev": "nodemon app.js" 
    ```
